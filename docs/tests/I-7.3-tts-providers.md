# Test-Matrix: 7.3 TTS-Provider

Issue: Roadmap 7.3 — das Paket `internal/tts` (spec `overlays.md`
B41, B54, ADR-0020 §3): die Datei-Provider `google` (REST), `azure`
(REST, SSML) und `piper` (externer Prozess); der Provider `browser`
spricht auf der Overlay-Runtime und erzeugt keine Datei. Die Keys
kommen nur aus der Umgebung und nie in Logs; die erzeugten Dateien
landen unter `<media-dir>/generated/`.

| Test | Datei | Deckt ab |
|---|---|---|
| `TestGoogleCoversSynthesizeAndKeyHandling` | `internal/tts/tts_test.go` | B41/B54: POST mit Text und der Abbildung von Lautstärke (50 → ≈ −6 dB), Sprechrate (1.5) und Tonhöhe (1.5 → +10 Hz) im `audioConfig`; der Key steht im Header `x-goog-api-key` und **nie** in der URL; die base64-Antwort wird als `tts-<zeitstempel>.mp3` unter dem Generated-Verzeichnis geschrieben; fehlender Key ist ein klarer Fehler, der die Env-Variable nennt. |
| `TestGoogleCoversTheAPIError` | `internal/tts/tts_test.go` | B54: ein API-Fehler trägt die Antwort im Fehler, der Key bleibt draußen. |
| `TestAzureCoversSSMLAndKeyHandling` | `internal/tts/tts_test.go` | B41/B54: POST mit SSML (Sprache aus dem Vornamen der Stimme, `name` der Stimme, `prosody` rate/pitch/volume in Prozent: 1.2 → `+20%`, 0.9 → `−10%`, 80 → `−20%`), XML-Escapes im Text; Output-Format `audio-24khz-48kbitrate-mono-mp3`; der Key im Header `Ocp-Apim-Subscription-Key`, nie in der URL; fehlender Key und fehlende Region sind klare Fehler, die die Env-Variablen nennen. |
| `TestPiperCoversTheProcessAndModel` | `internal/tts/tts_test.go` | B41: der Prozess läuft mit `--model <tts-piper-model>`, `--output_file <erzeugte Datei>`, `--length-scale 1/rate` und `--volume v/100`; der Text geht auf stdin; die geschriebene Datei wird zurückgegeben; fehlendes Modell ist ein klarer Fehler, der `tts-piper-model` nennt. Der Pitch geht verloren (piper kennt kein Pitch-Flag — Shortcut, ADR-0020-Nachtrag). |
| `TestGenerateCoversTheProviderNames` | `internal/tts/tts_test.go` | B41: `browser` erzeugt keine Datei (klarer Fehler, verweist auf das Overlay); unbekannter Provider ist ein klarer Fehler. |
| `TestNewCoversTheGeneratedDir` | `internal/tts/tts_test.go` | ADR-0020 §3: der Service braucht das Generated-Verzeichnis unter dem Medienverzeichnis des Profils. |

Nicht abgedeckt: die echten Cloud-APIs (nur httptest-Fakes — die
Abbildung der Parameter ist geprüft, nicht die Provider-Antworten) und
der echte piper-Prozess (Fake-`PiperRun`; die Prozess-Klammer läuft im
App-Wiring `piperRun`).
