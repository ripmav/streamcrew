# Test-Matrix: 7.5 Overlay-Aktion

Issue: Roadmap 7.5 — die Erweiterungen der `overlay`-Aktion
(`internal/action/overlay`, spec `overlays.md` B31, B33, B35, B38):
die vier neuen Widget-Operationen `add_to_credits`, `play_credits`,
`spin_wheel`, `damage_stream_boss` und das Item-Kind
`emote_effect` mit dem neuen `Emotes`-Port. Die 7.2-Tests derselben
Datei stehen in [I-7.2-overlay-action.md](I-7.2-overlay-action.md).

| Test | Datei | Deckt ab |
|---|---|---|
| `TestOverlayValidate` (7.5-Fälle) | `internal/action/overlay/overlay_test.go` | B33/B35/B38: Validierungstabelle um die neuen Fälle erweitert — `spin_wheel` mit Betrag ist ungültig, `play_credits` gültig, `damage_stream_boss` mit Betrag (und `data.force`) gültig, ohne Betrag ungültig; Item-Kind `emote_effect` mit `emotes` gültig, ohne `emotes` und mit unbekanntem `effect` ungültig. |
| `TestOverlayWidgetOps` (7.5-Operationen) | `internal/action/overlay/overlay_test.go` | B31/B33/B30/B38: die neuen Operationen laufen auf den Widget-Ports — `add_to_credits` (Sektion aus `data`, Eintrag aus `text`), `play_credits`, `spin_wheel` (User = Scope-User) und `damage_stream_boss` (Betrag, `data.force`); `add_to_credits` ohne Sektion in `data` ist ein klarer Fehler — der Widget-Port wird nicht aufgerufen, der Command läuft wegen der Fehlerpolitik (`ErrorContinue`) fertig. |
| `TestOverlayEmoteEffectItem` | `internal/action/overlay/overlay_test.go` | B35: das Item-Kind `emote_effect` löst die Namen über den Emote-Katalog (Port `Emotes`) auf; `maxShown` begrenzt die gezeigten Emotes über die Liste (2+1 bei `perEmoteShown` 2); `allowEmoji` lässt unbekannte Namen ohne Bild als Text stehen, ohne sie fallen sie weg; der Default-Effekt ist `random`; ohne einen auflösbaren Emote ist das Item ein klarer Fehler — es wird nichts gezeigt, der Command läuft fertig. |

Test-Infrastruktur: das 7.2-Test-Harness (Synctest-Bubble, Engine mit
Fake-Overlay und Fake-Widget-Operationen); das `fakeWidgets`-Fake
erweitert um die vier neuen Operationen (`credits`, `wheels`,
`bosses`); `testEmotes` ist der Emote-Katalog des Fakes
(`Kappa`, `Pog`); die Fake-Overlay-Instanz zählt die gezeigten Items.

Nicht abgedeckt: die Auslösung des Effekts in der Runtime (der
Content-Push ist hier abgedeckt, die Rendering-Logik in
`internal/overlay/runtime`) und der serverseitige Spin-Wurf
(`internal/overlaywidgets`, `TestWidgetWheel`).
