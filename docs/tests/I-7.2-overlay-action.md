# Test-Matrix: 7.2 Overlay-Action

Issue: Roadmap 7.2 — die Aktion `overlay` (`internal/action/overlay`): Kind `item`
(Items auf einem Endpunkt zeigen) und Kind `widget` (Operationen auf den Widgets des
Profils), `VisualAudio` und `PlaybackEnds` (spec `overlays.md` B9, B10, B11, B13, B14,
B16, B18, B21–B23, B38, B39, B43, B46).

| Test | Datei | Deckt ab |
|---|---|---|
| `TestOverlayValidate` | `internal/action/overlay/overlay_test.go` | B9/B10/B13/B38: die Kinds `item`/`widget`, Position (Modell, Punkt, Prozent 0–100, Pixel ≥ 0), Animationen, nicht-negative Dauern, die Inhalts-Mitglieder je Item-Kind (fremde Mitglieder, fehlende Pflichtwerte, YouTube-Größe, Clip URL oder Nutzer, Timer-Dauer/ Richtung), die Widget-Operationen (unbekannt, `amount` nur bei `add_to_goal`/`add_to_timer`, `data` nur bei `update`, `text` nur bei `add_to_event_list`), leere Widget-IDs und die Optionen des anderen Kinds (beide Richtungen). |
| `TestOverlayItemWaitsForEnd` | `internal/action/overlay/overlay_test.go` | B11/B14: die Aktion ist erst fertig, wenn das Item die aktive Menge verlässt; der End-Kanal des Overlay-Service trägt das Ende; der gerenderte Inhalt landet im Item. |
| `TestOverlayItemInGreeting` | `internal/action/overlay/overlay_test.go` | B11/B39/B43: das Ton-Item einer Begrüßung meldet sein Wiedergabe-Ende (`PlaybackEnds`); das Item der nächsten Begrüßung zeigt erst den Standard-Abstand (5 s, `EntranceMediaGap`) danach — die Instanzen starten sofort, nur die Aktion wartet auf den Gate. |
| `TestOverlayClipItem` | `internal/action/overlay/overlay_test.go` | B13/B16: ein Clip-Item per Nutzer löst den neuesten Clip des Kanals auf (Fake-Auflösung), die Dauer des Clips landet im Inhalt. |
| `TestOverlayClipItemRejectsForeignURLs` | `internal/action/overlay/overlay_test.go` | Review 344-6s/B15: nur Twitch-Clip-Seiten (`https://clips.twitch.tv/<slug>`, `https://www.twitch.tv/<kanal>/clip/<slug>`) landen im Item — `javascript:`, fremde Hosts, `http`-Varianten und Seiten ohne Slug sind ein Fehler der Action. |
| `TestOverlayItemWithoutADurationFallsAfterTheDefault` | `internal/action/overlay/overlay_test.go` | B11/B14, Review 344-5: ein Item ohne Dauer zeigt die Standard-Dauer von 10 s (Text), ein Clip-Item nach einem Nutzer die Dauer des Clips (30 s, nicht der Default), und Ton-Items ohne Dauer laufen bis zum `item.ended` — danach ist das Item aus der aktiven Menge gestrichen. |
| `TestOverlayInterruptedActionRemovesItsItem` | `internal/action/overlay/overlay_test.go` | Review 344-5/B46: eine abgebrochene (Cancel) oder zeitlimitierte Action entfernt ihr Item aus der aktiven Menge — über den echten Service verschwindet das Item, über den Fake ohne abgebrochenen Context (`context.WithoutCancel`). |
| `TestOverlayWidgetOps` | `internal/action/overlay/overlay_test.go` | B21–B23/B38: `show`/`hide` auf dem Overlay-Service, `update` beim Timer-Widget (neue Dauer), `add_to_timer` (Sekunden, negativ erlaubt), `pause_timer`, `add_to_goal` (negativer Betrag, Plattform und Nutzer der Ausführung), `update` bei anderen Kinds als Zustandsdaten durchgereicht, `add_to_event_list` mit gerendertem Text. |
| `TestClipsDecodeTheRealAPIShape` | `internal/helix/clips_test.go` | B13/B16, Review 344-N1: `ListClips` und `LatestClip` decodieren eine echte Helix-Beispielantwort — `duration` ist eine JSON-Zahl (29.9), keine Zeichenkette; `LatestClip` fragt das letzte Wochenfenster ab (`started_at`) und nimmt den Clip mit dem neuesten `created_at`, nicht den meistgesehenen, den die API zuerst listet. |

Nicht abgedeckt: die 7.5-Widget-Operationen (`add_to_credits`, `play_credits`,

mit 7.5 getestet; das eigentliche Clip-Ende der Twitch-URL (Fake), die Medien-
Wiedergabe in der Runtime (7.4/7.5).
