# Test-Matrix: 4.6.1 IRC-Chat für zusätzliche Kanäle

Issue: Roadmap 4.6.1 — IRC-Chat als Chat-Adapter für zusätzliche Kanäle (spec twitch-multi-channel.md, B15–B20).

| Test | Datei | Deckt ab |
|---|---|---|
| `TestPlatformIRCMode` | `internal/twitch/platform_multi_test.go` | B16: Der Home-Kanal behält seine EventSub-Session, der zusätzliche Kanal läuft nur über die IRC-Session (kein zweiter EventSub-Connect, der Bot-Token verlässt EventSub), `Streamer`/`Bot`-Status werden gesetzt und beim Abbruch wieder zurückgenommen. |
| `TestIRCSessionMessage` | `internal/twitch/irc_test.go` | PRIVMSG mit Twitch-Tags (id, user-id, badges, emotes, display-name, color) wird über dieselbe Mapping-Schicht wie der EventSub-Pfad zum `ChatMessage`-Ereignis gemappt, Channel-Stamp mit dem Login. |
| `TestIRCSessionMessageFromBot` | `internal/twitch/irc_test.go` | B13: Eine eigene Nachricht des Bot-Accounts (bot-ID im Tag) kommt mit `FromBot=true` an. |
| `TestIRCSessionDedup` | `internal/twitch/irc_test.go` | Dasselbe `id`-Tag zweimal (IRC-Redelivery) wird gefiltert; verschiedene IDs kommen beide durch. |
| `TestIRCSessionClear` | `internal/twitch/irc_test.go` | `CLEARMSG` (Mod-Delete) wird wie der EventSub-Pfad zu `ChatMessageDelete` gemappt, mit der Ziel-Nachricht-ID. |
| `TestIRCSessionWhisper` | `internal/twitch/irc_test.go` | B16/4.4: Der Whisper kommt ohne Channel-Stamp als `ChatWhisper`-Ereignis an; normale Chatnachrichten bleiben im Kanal. |
| `TestIRCSessionModStatus` | `internal/twitch/irc_test.go` | B17: Der Mod-Status kommt aus dem `badges`-Tag des `USERSTATE` nach dem Join (`moderator/1`); `IsModerator` meldet Status und, dass der `USERSTATE` eingetroffen ist — bei keinem Mod-Badge wird `mod_missing` gelogt statt eines Fehlers. |
| `TestIRCSessionSend` | `internal/twitch/irc_test.go` | B18: `Send` schreibt `PRIVMSG #<login> :text`; ein Text über das Plattform-Limit wird wie im Helix-Pfad gesplittet, ohne das Text zu verlieren. |
| `TestIRCSessionReconnect` | `internal/twitch/irc_test.go` | Ein abgebrochenes IRC-Setup wird mit Backoff neu verbunden und die Kanäle neu gejoined (B16). |
| `TestSettingsChatAdapter` | `internal/settings/settings_test.go` | B15: `chatAdapter` akzeptiert `eventsub`/`irc` (leer zählt als `eventsub`), ein fremder Wert bricht das Laden mit dem Adapter im Fehler ab. |
| `TestChannelsChatCommand` | `internal/cli/channels_test.go` | B15: `profile channels chat irc` schreibt das Setting, `profile channels list` zeigt den Adapter. |
| `TestScopes` | `internal/auth/scopes_test.go` | B18: `chat:write:bot` steht in der Pflicht-Liste (Tabelle ADR-0014, 42 Scopes). |

Nicht abgedeckt: der echte Twitch-IRC-Server (TLS, Rate-Limits, `NOTICE` bei Follower-Only-Chat) — er ist nur im E2E mit echten Konten prüfbar; die Server-Seite der Tests ist der Fake-IRC-Server in `irc_test.go`, der das Twitch-Drahtformat spricht.
