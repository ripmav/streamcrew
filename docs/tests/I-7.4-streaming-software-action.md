(`internal/action/streaming`, spec `overlays.md` B42, B55): Kinds
`set_scene`, `start_stream`, `stop_stream`, `start_recording`,
`stop_recording`, `save_replay`, `set_source` (Sichtbarkeit und/oder
Position einer Quelle der aktuellen Szene) und `set_filter`
(Sichtbarkeit eines Filters); ohne aktive OBS-Verbindung ist jede
Ausführung ein klarer Fehler des Aktions-Schritts.
