# Test-Matrix: I-6.6.3 TUI-Einstellungen

Roadmap 6.6 (On-the-fly-Konfiguration), 6.6.3: TUI-Ansicht 8 „Einstellungen“.
Zeigt das Konfigurationsdokument der `ConfigService` mit einer Annotation je
Einstellung: ⚡ hot (gelten ohne Neustart), ⟳ restart, ✋ fixiert (per
Flag/Env). `e` öffnet das Dokument in `$EDITOR` und speichert es über
`UpdateConfig`; `r` lädt neu. Nicht-Server-Modus: read-only.

## Erwartetes Verhalten

| Fall | Erwartet |
|---|---|
| Ansicht öffnen (Taste 8 / Tab) | `Get` wird aufgerufen, Dokument wird gerendert, Kopfzeile `live: live` (Server) bzw. `read-only` (Daemon/Desktop) |
| Annotation | je Dokumentzeile (Key vor dem ersten `:`) ⚡/⟳/✋ laut Listen des Get-Responses |
| `e` (live) | Dokument in tmp-Datei, `$EDITOR` (blocking), danach `UpdateConfig`; Ergebniszeile `applied: … · restart: …` |
| `e` (read-only oder Fehler) | passiert nichts |
| `e` ohne `$EDITOR`/`$VISUAL` | Fehlermeldung (keine Aktion) |
| `r` | Dokument neu laden |
| Fehler des Get | Fehler wird in der Ansicht gezeigt |
