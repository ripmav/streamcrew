# Test-Matrix: Phase 6.4 TUI-Grundgerüst (Bubble Tea v2)

| Test | Deckung |
|---|---|
| `TestKeyBindings` | Theme-Wechsel `t`, Hilfe `?` (öffnen/schließen, isst Keys), Ansichtswechsel `1`–`7` und `tab` (Wrap) |
| `TestQuit` | `q` liefert das `tea.Quit`-Kommando |

| `TestViewRendering` | Layout (Header, „connecting …", Footer mit Tasten, AltScreen), Hilfe-Ansicht |

| `TestThemeToggles` | Helles und dunkles Theme rendern unterschiedlich |
| `TestRunQuits` | Komplettes Programm (Piped-Input, WithoutRenderer): `q` beendet sauber |
| Komplettsuite | Kong-Struktur (`tui` im Befehlsbaum), Completion-Coverage, alle übrigen Pakete |

## Randfälle

- Kein `runtime.json` und kein `--server` ⇒ Default-Adresse (Daemon-Modus)
- `runtime.json` mit `unix:`-Adresse ⇒ Unix-Dialer (Desktop-Modus)
- Hilfe offen ⇒ alle Keys außer `q`/`?`/Esc werden ignoriert
- Fehler + kein Status ⇒ Fehlerbanner statt „connecting …"
